# Power Automate / kintone 初回整理サンプル

目的: Power Automate や kintone の本格導入前に、業務の目的、入力、処理、出力を整理するための初回診断サンプル。

## 初回で確認すること

- 目的: 何の手作業、見落とし、二重入力を減らしたいか
- 入力: フォーム、メール、Excel、紙、既存システムのどれか
- 処理: 転記、承認、通知、集計、ステータス更新のどれか
- 出力: Teams通知、メール、管理表、レポート、kintoneアプリのどれか
- 利用者: 誰が入力し、誰が確認し、誰が修正するか
- 権限: 管理者権限、外部連携、個人情報の有無

## 初回価格の考え方

- 15,000円: 現状整理、初回フロー選定、必要権限メモ
- 50,000円: 1フローの試作、動作確認、簡易手順書
- 月額30,000円から: 項目追加、通知文修正、月1改善相談

## 対応外

- 管理者権限を使う本番環境変更の契約前作業
- セキュリティ、法務、個人情報管理の最終判断
- 既存基幹システムの直接改修
- 無断スクレイピング、大量送信、規約回避
